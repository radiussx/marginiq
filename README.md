# MarginIQ

Retail Profitability Intelligence Platform built with Java 21, Spring Boot, PostgreSQL, Redis, and Next.js.

## What it does
- Tracks products, suppliers, inventory, and sales
- Calculates revenue, cost, estimated profit, and margin
- Classifies products into business opportunity/risk segments
- Simulates promotions and discounts
- Exposes analytics REST APIs
- Provides a React/Next.js dashboard

## Run
```bash
docker compose up --build
```

Backend: http://localhost:8080  
Swagger UI: http://localhost:8080/swagger-ui.html  
Frontend: http://localhost:3000
